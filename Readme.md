# MPC-HC Sidebar

基于 [MPC-HC 2.8.5](https://github.com/clsid2/mpc-hc/releases/tag/2.8.5) 的 Windows 视频播放器增强版，加入文件夹浏览侧栏和长按临时倍速。

这是独立修改版，不是 MPC-HC 官方发行版。原播放器及第三方组件的署名、版权和许可证保留。

## 新增功能

- **文件夹侧栏**：选择文件夹后浏览视频，单击视频播放；有 FFmpeg 时显示缩略图。
- **分层浏览**：父目录视频优先，子文件夹默认折叠，支持逐层展开和收起。
- **统一排序**：按名称、创建时间、修改时间或大小升降序排列，选择会保存。
- **空白启动**：启动时不读取上次目录；点击“打开上次文件夹”继续浏览。
- **连续滚动**：支持滚轮、可拖动滚动条和键盘导航；目录与缩略图在后台加载。
- **临时倍速**：播放区域按住左键约 0.45 秒进入 2 倍速，向右拖动最高 5 倍，松开恢复原速。
- **纯白倍速提示**：只显示数字，无阴影或描边；工具栏加减速按钮可在设置中显示。

## 下载与使用

从本仓库 **Releases** 下载 `MPC-HC-Sidebar-2.8.5-sidebar.1-x86.zip`，解压到可写文件夹，运行 `mpc-hc.exe`。此包包含播放器及官方运行组件，不需要安装到原播放器目录。

当前提供 **x86** 构建，可在 64 位 Windows 上运行；本次实际验证环境为 Windows 11。没有提供未经验证的 x64 构建。

### 启用缩略图

缩略图需要独立的 `ffmpeg.exe`，发布包没有捆绑 FFmpeg。

1. 从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html#build-windows) 所列的 Windows 构建来源下载 FFmpeg。
2. 在播放器目录新建 `SidebarTools` 文件夹，将所下载的 `ffmpeg.exe` 放入。
3. 重新选择文件夹或点击“刷新”。

文件结构如下：

```text
mpc-hc.exe
mpc-hc.ini
SidebarTools/
  ffmpeg.exe
```

没有 FFmpeg 时仍可浏览文件夹和播放视频，缩略图显示“视频”占位。FFmpeg 的架构需要与 Windows 匹配；它作为独立进程运行，不要求与播放器同为 x86。

## 操作

底部“打开侧栏／收起侧栏”按钮或 `Ctrl+Shift+B` 控制侧栏。文件夹行左侧的三角箭头用于展开和收起。

| 操作 | 作用 |
| --- | --- |
| 单击视频 | 播放所选视频 |
| 单击文件夹 | 展开或收起 |
| 上／下方向键 | 选择上一项或下一项 |
| 左／右方向键 | 收起或展开选中的文件夹 |
| Page Up／Page Down | 按可见区域移动 |
| Home／End | 跳到首项或末项 |
| Enter／空格 | 播放视频或切换文件夹展开状态 |
| 刷新 | 重新读取当前目录，并收起子文件夹 |

长按倍速适用于视频画面和黑边；移动窗口请拖动标题栏。速率按钮可在“选项 → 播放器 → 工具栏布局”中开启。

## 设置和缓存

便携包中的 `mpc-hc.ini` 是新建的空白配置，未携带任何使用记录。使用后，设置和历史记录会写入所在文件夹；缩略图缓存默认为同目录的 `FolderCache`。

自行编译且未启用便携模式时，缓存跟随 MPC-HC 的配置目录。已有自定义 `VideoFolder/CachePath` 会保留。分享使用过的程序目录之前，请重新取得干净的发布包，避免把后续生成的配置、历史和缓存一并发送。

## 构建与验证

见 [构建说明](docs/Sidebar-Build.md)、[本版更新说明](docs/Sidebar-Release.md) 和 [第三方组件来源](docs/Sidebar-Third-Party.md)。

回归检查覆盖目录分组、排序、折叠、多层展开、空目录、无效目录、Unicode 文件名、10 万行滚动位置边界及倍速手势状态。真实窗口检查覆盖 700 视频列表滚动、播放、重启、720×480 布局和纯白倍速提示。

文件夹联接和目录符号链接不展开，以避免循环。网络目录、全部编解码器与渲染器组合、多显示器 DPI 切换未全面覆盖。持久化倍速数值与可支持的最高播放速率仍受媒体和渲染器影响。
