# 2.8.5-sidebar.1

基于 MPC-HC 2.8.5 的首个 Sidebar 修改版，新增文件夹侧栏和临时倍速操作。

## 功能

- 文件夹视频列表和可选缩略图，支持单击播放。
- 父目录视频优先，子文件夹默认折叠，多层按需展开。
- 名称、创建时间、修改时间、大小的升降序排序。
- 启动保持空列表，通过“打开上次文件夹”继续浏览。
- 后台读取目录和缩略图，长列表滚动条使用完整 32 位位置。
- 长按约 0.45 秒临时 2 倍速，向右拖动最高 5 倍，松开恢复。
- 倍速数字为纯白，无阴影、描边或彩色虚边。
- 底部侧栏开关和可配置的工具栏速率按钮。

## 下载

`MPC-HC-Sidebar-2.8.5-sidebar.1-x86.zip` 是可解压运行的 x86 包。程序基于官方运行组件，使用新建的空白便携配置。缩略图 helper FFmpeg 需按 README 另行安装。

`SHA256SUMS.txt` 用于校验发布附件。源码位于本仓库对应标签，构建前初始化固定版本的子模块。

## 已完成检查

Release / Win32 构建、目录模型和手势回归测试、10 万行滚动位置边界、700 视频真实窗口滚动、层级展开、排序、播放、重启、720×480 窗口和倍速数字显示。
